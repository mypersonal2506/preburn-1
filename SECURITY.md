# Security policy

## Supported versions

Only the latest minor release gets security fixes. Upgrade to it to receive them.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting. Open the [Security tab](https://github.com/preburn/preburn/security) of this repository and click "Report a vulnerability". Do not open a public issue, pull request or discussion.

Include:

- the affected version, or the commit if you run from source
- the affected component: api, worker, dashboard or the `preburn` command
- steps to reproduce, with a proof of concept if you have one
- the impact, such as what an attacker can read or change
- any configuration the issue depends on

## Response

A maintainer replies within 5 working days.
